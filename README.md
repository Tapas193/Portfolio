## About This Portfolio

A premium, minimal, recruiter-friendly personal portfolio built with a warm editorial design system.

**Features**
- Light and dark theme with a black/white toggle, saved in `localStorage` (`portfolio-theme`) and applied before paint to prevent theme flash
- Minimal intro loader (TAPAS MISHRA → PORTFOLIO) shown once per session
- Native OS cursor only — no custom cursor or decorative gimmicks
- Fully responsive, accessible contrast in both themes
- Centralized CSS-variable theme tokens

**Tech Stack**
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

**Getting Started**

```bash
npm install
npm run dev      # dev server (defaults to http://localhost:5173)
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # lint
```
